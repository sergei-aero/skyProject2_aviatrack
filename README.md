AviaTrack — это консольное приложение на Python для получения информации о самолётах, находящихся в воздушном пространстве заданной страны, с использованием открытых API (OpenSky Network и Nominatim). Данные сохраняются локально в форматах JSON или CSV, после чего пользователь может анализировать их: выводить топ самолётов по высоте, фильтровать по стране регистрации.

Проект разработан с соблюдением принципов SOLID, использует абстрактные классы, паттерны проектирования и лучшие практики объектно-ориентированного программирования.

#
Возможности

- Запрос списка самолётов в воздушном пространстве страны через OpenSky Network.

- Геокодирование страны (получение bounding box) через Nominatim OpenStreetMap.

- Сохранение данных в JSON или CSV (на выбор пользователя) в папку data/.

- Загрузка ранее сохранённых данных для анализа без повторного обращения к API.

- Вывод информации в виде таблицы.

- Определение топ-N самолётов по высоте полёта.

- Фильтрация самолётов по стране регистрации.

- Интерактивный консольный интерфейс.
#
Технологии

- Python 3.9+

- requests — для HTTP-запросов к API

- python-dotenv — для загрузки переменных окружения

- pytest, pytest-cov, requests-mock — для тестирования и измерения покрытия

- Стандартные библиотеки: json, csv, abc, typing, os, sys, pathlib
